# HushHunt

3:3 비대칭 온라인 데스매치. 숨는 팀과 잡는 팀이 안개 짙은 밤의 숲에서 맞붙습니다.

## 프로젝트

HJJHGame은 HushHunt를 개발하고 있습니다. 현재 Unity 6 기반 프로토타입 단계입니다.

- 3:3 팀 대전: 숨는 팀 vs 잡는 팀
- 분위기: 짙은 안개, 어두운 밤, 소나무 숲
- 현재 구현: 1인칭 이동, 발소리, 미니맵
- 개발 예정: 전투, 네트워크, 승패 판정
