# HushHunt

3:3 비대칭 온라인 데스매치. 숨는 팀과 잡는 팀이 안개 짙은 밤의 숲에서 서로를 사냥합니다.

## 게임

- 데스매치 + 숨바꼭질 + 술래잡기를 합친 1인칭 PvP
- 숨는 팀은 샷건, AR, 발차기로 버티고, 잡는 팀은 호루라기만 들고 시작해 시간이 지날수록 스나이퍼로 무장합니다
- 발소리와 총알이 지도에 표시되는 정보 싸움
- 초반엔 숨는 팀, 후반엔 잡는 팀이 유리한 역전 구조
- Steam 출시를 목표로 개발 중입니다
